# Security

Please do not publish passwords, API keys, tokens, private keys, personal photos, or private network credentials in issues or pull requests.

For a suspected security problem, avoid publicly posting secrets or exploit details. Open a private security report through the repository's available GitHub security reporting mechanism.

## Local credentials

Store secrets in environment variables or an ignored .env file. Commit only example configuration with blank values.

## Hardware safety

Test motor systems with the wheels lifted from the ground. Use appropriate power supplies, common grounds where required, and logic-level protection between 5 V and 3.3 V systems.
