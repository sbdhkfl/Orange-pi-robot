# Troubleshooting checklist

Use this order:

1. Power
2. Wiring
3. Firmware
4. Network
5. Software dependencies
6. Logs
7. Feature-specific configuration

Never assume a software failure is caused by AI. First verify that the hardware works by itself.

When reporting a bug, include:
- Board and exact hardware revision
- Operating system or firmware version
- Exact command used
- Complete error message
- What worked before the failure
- Wiring changes
- Relevant serial or system logs
- Whether the failure is repeatable
