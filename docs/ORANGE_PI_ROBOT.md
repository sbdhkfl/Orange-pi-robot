# Orange Pi AI Robot Project

The Orange Pi Zero 3 is the main computer. The Arduino Uno handles low-level motor and sensor control.

This project is intentionally separate from the ESP32 XiaoZhi Bot.

## Build order

1. Boot Orange Pi
2. Configure Wi-Fi
3. Confirm the 64GB SD card/Linux installation
4. Test USB camera
5. Connect Orange Pi to Arduino safely
6. Test Arduino motor control
7. Test all four motors
8. Add ultrasonic obstacle sensing
9. Add audio
10. Add camera vision
11. Add face recognition
12. Add object detection
13. Add voice commands
14. Add autonomous behavior
15. Add email/photo notifications
16. Integrate the complete robot

## Software goal

Prefer free and open-source software. Avoid paid proprietary AI APIs where practical.

## Important

The robot should not control unrelated ESP32 devices around the home.
